# Code of conduct

Lleme is a technical project. We want people to be able to take part in
it without being mistreated, whatever their background, identity or
level of experience.

This code applies to the project's repositories, discussions, chat
channels and any other space run by the project, and to anyone
representing the project in public.

## Expected behavior

- Be respectful, including when you disagree.
- Criticize the code and the idea, not the person.
- Assume good intent, and ask before you conclude otherwise.
- Accept review comments as part of the work, and give them with care.
- Write so that people reading in a second language can follow you.
- Respect the time of maintainers and of other contributors.

## Unacceptable behavior

- Harassment, insults, or demeaning comments about a person or a group
- Sexual language or imagery, and unwelcome sexual attention
- Threats or intimidation
- Publishing someone's private information without their permission
- Repeated disruption of discussions, or sustained hostility after
  being asked to stop
- Flooding the project with content you have not read or reviewed

## Reporting

If you experience or witness behavior that breaks this code, write to
`conduct@lleme.dev`. Say what happened, where and when, and include
links or screenshots if you have them.

Reports are read by the project maintainer and are kept confidential.
We will not share who reported without that person's agreement.

If your report is about the maintainer, say so in the report. It will
be recorded, and you may also use the reporting tools of the platform
where it happened.

## Enforcement

A maintainer decides what to do, in proportion to what happened:

1. **Correction.** A private note explaining what was wrong.
2. **Warning.** A written warning with the consequence of repeating
   the behavior.
3. **Temporary block.** No participation in the project's spaces for a
   set period.
4. **Permanent block.**

Maintainers may remove, edit or reject comments, commits, issues and
other contributions that break this code.

Maintainers are bound by this code as well.

## Changes

Changes to this code are made by pull request, like any other document
in the repository.
