# Lleme

Lleme is an LLM gateway with routing and observability, in early
development. It is being built to accept requests in the OpenAI and
Anthropic formats, choose a model by rule, and record traces and cost
for every call, running as a native server in a container and as a
Cloudflare Worker. Nothing is usable yet. Lleme is licensed under the
GNU Affero General Public License, version 3 only; see `LICENSE`.
